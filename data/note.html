UNIT Ⅰ

개인 생활과 법

01 가족생활과 법 혼인·이혼·친자·상속

① 부부간의 법률관계

  • 법률관계: 법의 규율 대상이 되는 생활관계 (↔ 호의관계: 법적 의무 없음) 비교 포인트
  • 민법: 개인 간 법률관계(재산관계·가족관계) 규율 → 사적 자치의 원칙(=계약 자유의 원칙)이 기본 원리
  • 민법 구조: 재산법(총칙·물권·채권) + 가족법(친족·상속)
  • 혼인 성립 요건: 18세 이상(미성년자는 부모 동의) + 혼인 의사 + 근친 아님 + 혼인 신고 필수 → 신고 없으면 사실혼(제한적 보호)
  • 혼인의 효과: 친족관계 발생, 부양·협조 의무, 미성년자 혼인 시 성년 의제, 부부 별산제(원칙), 일상 가사 대리권·연대 채무
  • 이혼: 협의 이혼(이혼 숙려 기간 → 이혼 신고 시 효력) / 재판상 이혼(민법 제840조 사유 필요 → 판결 확정 시 효력)
  • 이혼의 효과: 친족관계 소멸(부모-자녀 관계는 유지), 면접교섭권, 재산분할청구권, 위자료청구권
⚠ 자주 틀리는 포인트부부 별산제는 "별도 약정이 없을 때" 적용 / 혼인 중 부부 협력 취득 재산은 명의와 무관하게 공동재산 인정 / 일상가사 채무는 부부 연대책임(남편만 X)

② 부모와 자녀 간의 법률관계

  • 친자관계: 혈연(친생자) 또는 입양(양자)으로 형성
  • 친생자 = 혼인 중의 출생자(법률혼) + 혼인 외의 출생자(모: 출산으로 당연 인정 / 부: 인지 필요)
  • 일반 입양: 합의 필요(미성년자 입양은 가정법원 허가) → 양자는 양부모 친생자와 같은 지위 + 친생부모와 친족관계 유지(상속권 有)
  • 친양자: 가정법원 인가 → 양부모의 혼인 중 자녀로 간주, 양부모 성·본 따름, 친생부모와 친족관계 종료 최다출제
  • 친권: 부모가 미성년 자녀에게 갖는 신분·재산상 권리·의무 (오늘날 '의무'적 성격 강조) → 자녀 복리 최우선, 부모 공동행사 원칙
💡 비교 포인트: 일반입양 vs 친양자일반입양=친생부모와 관계 유지·상속권 존재 / 친양자=친생부모와 관계 단절·양부모 성본 사용

③ 유언과 상속

  • 유언: 사후 재산관계를 미리 정하는 법률행위, 17세 이상이면 가능, 5가지 법정 방식(자필증서·녹음·공정증서·비밀증서·구수증서) 중 하나로만 유효
  • 유류분: 유언과 무관하게 일정 상속인에게 보장되는 최소한의 상속분
  • 법정 상속 순위: 1순위 직계비속 → 2순위 직계존속 → 3순위 형제자매 → 4순위 4촌 이내 방계혈족 / 배우자는 1·2순위와 공동상속(선순위자 없으면 단독상속), 공동상속 시 50% 가산
  • 상속의 승인·포기: 상속에는 재산뿐 아니라 채무도 포함 → 단순승인/포기/한정승인 선택 가능(가정법원 청구)
  • 2026년 시행 개정 민법: 양육 의무를 저버리거나 학대한 부모의 상속권 상실 선고 제도 신설(제1004조의2) 최신 개정

  • 협의이혼 vs 재판상이혼 절차·효력 발생 시점 구분
  • 일반입양과 친양자의 차이(친생부모와의 관계) 설명 가능
  • 법정상속순위 및 배우자 상속분 계산 가능
  • 유류분·상속포기·한정승인 개념 구분

02 계약과 불법 행위 계약 성립·채권채무·불법행위

① 계약의 성립과 효력

  • 계약: 청약 + 승낙의 합치로 성립(계약서 작성은 성립 요건 아님, 증거자료 기능) — 계약 자유의 원칙
  • 근대민법 3대원칙 → 수정: 소유권 절대 원칙→소유권 상대화 / 계약자유 원칙→일부 제한(공서양속 위반 시 무효) / 과실책임 원칙→무과실책임 부분 도입 최다출제
  • 계약의 효력: 채권(청구할 권리) ↔ 채무(이행할 의무) 발생, 동시이행 관계는 임의규정(당사자 합의로 변경 가능)
  • 채무불이행: 강제이행 청구, 손해배상 청구, 계약 해제 가능
  • 미성년자 계약: 원칙적으로 법정대리인 동의 필요 → 동의 없으면 취소 가능(유효하지만 취소권 존재) / 단, 속임수(동의서·신분증 위조) 사용 시 취소 불가 / 용돈 처분, 허락된 영업, 임금 청구는 동의 불요
  • 상대방 보호: 확답 촉구권, (미성년자측 미추인 시) 상대방의 철회권

② 불법 행위와 손해배상

  • 불법행위 성립요건 5가지: ①고의·과실 ②위법성(정당방위·긴급피난 등은 위법성 조각) ③손해 발생 ④상당인과관계 ⑤책임능력 최다출제
  • 손해배상: 금전배상 원칙, 재산적 손해(적극적+소극적) + 정신적 손해(위자료) 모두 배상
  • 특수불법행위(자기 고의·과실 없어도 책임): 감독자책임/사용자책임/공작물책임/동물점유자책임 — 모두 "상당한 주의를 다했음을 증명하면 면책" 구조 공통
  • 2026년 개정: 미성년자 성적 침해 손해배상청구권의 소멸시효는 성년이 될 때까지 정지

  • 근대민법 3원칙과 현대적 수정 내용 짝짓기
  • 미성년자 계약 취소 가능/불가능 사례 구분(속임수 여부)

  • 특수불법행위 4유형과 면책요건 비교

03 재산 관계와 법 부동산·등기·임대차·담보

① 부동산 거래와 등기 제도

  • 물권: 물건을 직접 지배하는 권리 (↔채권: 특정인에 대한 청구권, 당사자 간에만 효력) — 물권은 종류·내용 임의로 정할 수 없음(물권법정주의)
  • 소유권: 사용·수익·처분 모두 가능 / 제한물권(용익물권: 지상권·지역권·전세권, 담보물권: 유치권·질권·저당권)
  • 부동산 vs 동산: 부동산=토지+정착물(등기로 공시) / 동산=그 외(점유로 공시)
  • 부동산 매매 계약: 매도인(소유권 이전의무)-매수인(대금지급의무) / 소유권 취득 시점 = 등기 완료 시(대금 지급·인도만으로는 소유권 취득 X, 민법 제186조) 최다출제
  • 등기부 구성: 표제부(소재지·면적·구조) / 갑구(소유권 관련사항) / 을구(소유권 이외 권리: 저당권·전세권 등)
💡 시험포인트등기부 갑구·을구·표제부 그림 문제 단골 출제 — "소유권"→갑구, "저당권·전세권"→을구, "면적·구조"→표제부

② 주택 임대차와 임차인의 권리 보호

  • 주택 임대차: 임대인(빌려줌)-임차인(빌림, 대가 지급) / 임차인은 원칙적으로 물권 없는 채권자 → 「주택임대차보호법」으로 특별 보호
  • 계약갱신요구권: 임차인 1회 행사 가능, 임대인은 정당한 사유 없이 거절 불가
  • 대항력: 주택 인도 + 전입신고(다음 날 0시부터 발생) → 소유자 변경돼도 계속 거주 가능
  • 우선변제권: 대항력 + 확정일자 → 경매 시 우선순위에 따라 보증금 변제 최다출제 공식
  • 임차권등기명령: 이사 후에도 대항력·우선변제권 유지하기 위한 제도
공식 암기실거주+전입신고 = 대항력  |  대항력+확정일자 = 우선변제권

③ 채권의 담보 제도

  • 인적 담보(보증): 채무자 아닌 타인이 대신 이행 — 서면 계약 필수, 채권 실현 확실성 상대적으로 낮음
  • 물적 담보(저당권): 특정 재산에서 우선 변제 — 저당권 설정 합의 + 등기 필요, 먼저 등기한 저당권자가 우선
  • 근저당권: 채권최고액 범위 내 불특정 다수 채권 담보(일반 저당권보다 유연, 실무상 일반적)
  • 물권과 채권의 차이(효력 범위) 설명 가능
  • 부동산 소유권 취득 시점(등기 시) 정확히 알기
  • 등기부 갑구·을구·표제부 구분
  • 대항력·우선변제권 성립 요건과 발생 순서 암기
  • 인적담보(보증)와 물적담보(저당권) 비교
📌 Ⅰ단원 통합 시험 포인트 1단원은 혼인·이혼·상속(가족관계)과 계약·불법행위(재산관계), 부동산·임대차가 3대 축입니다. 특히 "대항력+확정일자=우선변제권" 공식과 "불법행위 5요건", "친양자 vs 일반입양"은 매년 빠지지 않는 단골 문제입니다.
UNIT Ⅱ

국가 생활과 법

01 국가 운영 원리 민주주의·법치주의·권력분립

  • 민주주의: 국민 뜻에 따라 국가 의사 결정(목적=인간 존엄성) / 법치주의: 법에 근거해 국가기관 구성·운영(목적=자유·권리 보장) — 둘 다 헌법의 기본원리
  • 발전과정: 고대 아테네(직접민주정, 시민권=성인남성 한정) → 근대 시민혁명(명예혁명·미국독립혁명·프랑스혁명, 대의제·법치주의·입헌주의 성립) → 현대(보통선거, 직접민주제 요소 도입, 실질적 법치주의 대두)
  • 사회계약설 3인 비교 최다출제: 홉스(자연상태=투쟁, 전부 양도·회수불가) / 로크(자연상태=자유·평등이나 불안정, 일부 위임·저항권 인정) / 루소(자연상태=자유·평화, 일반의지로 통합·양도불가)
  • 직접민주제 요소: 국민투표/국민발안/국민소환 — 우리나라는 국민투표만 인정
  • 민주주의-법치주의 관계: 상호보완 원칙이나 긴장관계 가능 → 민주주의 결여된 법치주의=독재의 합법화 도구 / 법치주의 결여된 민주주의=포퓰리즘
  • 권력분립: 입법권(국회)-행정권(대통령·행정부)-사법권(법원) 분리, 상호 견제·균형 → 목적은 권력 남용 방지·국민 자유권 보장
  • 헌법재판소: 위헌법률심판, 헌법소원심판, 탄핵심판, 정당해산심판, 권한쟁의심판(5가지) 담당

03 형법과 형사 절차 죄형법정주의·범죄성립·형사절차

  • 죄형법정주의: "법률이 없으면 범죄도 형벌도 없다" → 현대는 "적정한 법률이 없으면..."(실질적 법치주의 반영)
  • 파생원칙 4가지 최다출제: 관습형법금지 / 소급효금지(행위자 유리하면 예외 허용) / 명확성 / 유추해석금지 — 모두 행위자에게 유리한 경우는 예외 인정
  • 범죄 3단계 성립요건: ①구성요건해당성 ②위법성(정당방위·긴급피난·자구행위·피해자승낙·정당행위 시 조각) ③책임(14세 미만·심신상실자·강요된 행위는 책임조각, 심신미약·청각언어장애는 형 감경만)
  • 형벌의 종류(9가지): 생명형(사형) / 자유형(징역·금고·구류) / 명예형(자격상실·자격정지) / 재산형(벌금·과료·몰수)
  • 보안처분: 형벌과 별개(재사회화 목적, 미래 위험성 대응) — 보호관찰·치료감호·사회봉사명령·수강명령 등
  • 형사절차 흐름: 수사(고소/고발/인지) → 검찰 송치·불송치 → 기소/불기소 → 공판(모두절차→심리절차→판결선고) → 형 집행
  • 인권보장 원칙: 적법절차원칙, 진술거부권, 변호인 조력권, 무죄추정원칙(미란다원칙 포함)
  • 인권보장 제도: 구속전피의자심문(=영장실질심사), 구속적부심, 보석제도, 공개재판주의, 증거재판주의, 불이익변경금지원칙, 일사부재리원칙

04 사법의 의미와 한계 법원·헌법재판소·법적삼단논법

  • 사법권의 독립: 법원 조직 독자적 구성, 법관 신분 강하게 보장(헌법과 법률·양심에 따라 심판)
  • 법원 조직: 대법원(대법원장+대법관) - 고등법원 - 지방법원(+특허법원·군사법원·가정법원·행정법원·회생법원)
  • 심급제도(3심제): 1심(지방법원 단독/합의부) → 2심(지방법원본원합의부 또는 고등법원) → 3심(대법원, 상고·재항고)
  • 헌법재판소: 재판관 9명(대통령 임명, 국회 선출 3+대법원장 지명 3+대통령 임명 3), 소장은 대통령이 국회 동의 얻어 재판관 중 임명
  • 헌법재판소 5대 심판: 위헌법률심판 / 헌법소원심판(권리구제형·위헌심사형) / 탄핵심판 / 정당해산심판 / 권한쟁의심판
  • 의결정족수: 위헌결정·탄핵결정·정당해산결정·헌법소원 인용 = 6명 이상 찬성 / 권한쟁의심판 = 과반수 찬성
  • 헌법불합치결정: 위헌이지만 즉시 무효화 시 혼란 → 법 개정 전까지 한시적 존속시키는 변형결정
  • 법적 삼단논법: 대전제(법규범) + 소전제(사실관계 확정) → 결론 도출
  • 사법 vs 입법·행정: 사법은 소극적·수동적(분쟁 발생 시에만 작동) / 입법·행정은 적극적·능동적
  • 3심제 흐름과 관할 법원(지방법원→고등법원→대법원) 암기
  • 헌법재판소 5대 심판과 청구 요건 구분
  • 위헌결정 등 의결정족수(6명 이상) 암기
  • 헌법불합치결정의 의미와 필요성 설명 가능
  • 법적삼단논법 구조(대전제-소전제-결론) 적용 문제 연습

03 현대 생활과 법 지능정보화·플랫폼노동·지적재산권

  • 현대사회 3대 변화: 저출생·고령화 / 세계화 / 지능정보화
  • 인터넷 서비스 제공자 책임: 원칙은 자기책임원칙(직접행위 없으면 무책임)이나, 저작권 침해 관리·감독 소홀 시 방조책임 인정 가능
  • 플랫폼 노동: 수요자-제공자-플랫폼의 삼각관계 → 「근로기준법」상 근로자 인정 여부가 쟁점(사회안전망 사각지대 문제)
  • 지적재산권: 창조적 활동으로 창출한 무형자산에 대한 재산권(헌법 제22조 제2항 근거)
  • 지적재산권 분류 최다출제: 저작권(문학·예술 창작표현) / 산업재산권(특허권·실용신안권·디자인권·상표권) / 신지적재산권(컴퓨터프로그램·반도체배치설계권 등 새로운 유형)
  • 저작재산권 보호기간: 저작자 생존기간 + 사망 후 70년
  • 지적재산권의 한계: 보호기간 만료 시 공유상태 전환 → 과도한 보호는 정보공유·후속연구 저해 가능

01 청소년의 특징과 법적 지위 청소년 권리·연령기준·촉법소년

  • 청소년: 소년+청년을 아우르는 말, 법률마다 연령기준 다름(예: 「청소년보호법」19세 미만 / 「청소년기본법」9~24세 / 「청년기본법」19~34세) 법률별 연령기준 혼동주의
  • 청소년도 권리·의무 주체이나 판단능력 부족 고려 → 법적 책임 제한/면제 + 국가·보호자의 보호 의무
  • 연령별 법적 권리 총정리 최다출제: 14세(형사처벌 가능, 개인정보 동의 가능) / 15세(연소근로자 고용 가능) / 16세(원동기면허) / 17세(주민등록증, 유언 가능) / 18세(성인근로자, 자동차면허, 혼인 성년의제, 병역준비역, 선거권·피선거권) / 19세(민법상 성인, 병역판정검사)
  • 형사미성년자 3단계: 범법소년(10세 미만, 보호처분X·형사처벌X) / 촉법소년(10~14세 미만, 보호처분O·형사처벌X) / 범죄소년(14~19세 미만, 보호처분O·형사처벌O)
  • 선거권 연령 변천: 1948년 21세 → 1960년 20세 → 2005년 19세 → 2020년 18세(현행)

02 학교생활의 법적 문제 학교폭력·학교규칙

  • 학교폭력: 학교 내외에서 학생 대상 발생한 상해·폭행·감금·협박·약취유인·명예훼손·모욕·공갈·강요·성폭력·따돌림·사이버폭력 등 → 피해자가 학생이면 가해자가 학생 아니어도 성립
  • 학교폭력 해결 방법 4가지 최다출제: 행정법적 해결(「학교폭력예방법」-피해학생보호·가해학생조치·분쟁조정) / 형법적 해결(14세 미만은 「소년법」보호처분) / 민법적 해결(손해배상청구) / 교육적 해결(상담·관계회복프로그램)
  • 법적 해결의 한계: 강제력은 있으나 비용·시간 소요, 감정적 치유·관계회복에는 한계 → 교육적 해결과 병행 필요
  • 학교규칙: 헌법·법률 등 법령 범위 내에서 제·개정, 학생대표가 의견수렴하여 학교운영위원회에 제안 가능
  • 학교생활 법적 쟁점: 휴대전화 사용 제한(수업권·학습권 vs 통신의 자유), 체벌·생활지도, 교권 침해 등

03 민주 시민의 법적 문제 해결 법령검색·법해석·입법

  • 법적 문제 해결에 필요한 4대 자료: 법(1차적 근거, 국가법령정보센터) / 조약(국제법규, 헌법에 의해 체결·공포되면 국내법과 같은 효력) / 판례(좁은 의미=법해석 기준, 법적 문제 해결의 보조적 근거) / 입법자료(법 제·개정 배경 파악)
  • 사회문제의 법적 해결 절차: ①문제현황 파악 → ②관련 법적자료(법·판례) 조사 및 해석 → ③해결방안 모색(입법 필요 시 입법 제안) → ④법 이외의 해결방안(교육·정책) 병행
  • 입법 시 유의점: 필요성 판단(다른 방법으로 해결 가능한지) / 특정집단 이익 편중 금지·균형 유지 / 소수의견 고려 / 법적 안정성 고려
  • 법으로 해결하기 어려운 문제는 교육·정책 등과 상호보완적으로 해결해야 함(예: 전동킥보드 안전문제 = 법적규제+안전교육+지자체 정책 병행)
  • 법·조약·판례·입법자료의 성격과 역할 구분
  • 사회문제의 법적 해결 4단계 절차 암기
  • 입법 시 고려해야 할 유의점 서술 가능
